# Welcome to Your UECA-React App

Congratulations! You've just created a new UECA-React application.

## What's Included

This template provides a minimal foundation with:

- **Core Infrastructure**: Complete UECA-React setup including routing, message bus, and application lifecycle
- **Component Library**: Ready-to-use UI components following UECA patterns
- **Layout System**: Pre-configured app layout with sidebar navigation
- **TypeScript Support**: Full TypeScript configuration optimized for UECA-React development

## Getting Started

### Project Structure

- `src/screens/` - Your application screens
- `src/components/` - Reusable UI components
- `src/core/` - Application infrastructure and layout
- `src/api/` - API clients and mock service handlers

### Next Steps

1. **Create Your First Screen**: Add new screens in `src/screens/`
2. **Define Routes**: Update `src/core/infrastructure/appRoutes.tsx`
3. **Extend Navigation**: Add menu items in `src/core/appLayout/appMenu.tsx`
4. **Build Components**: Create custom components following UECA patterns

## UECA-React Principles

Every component in UECA-React follows the same structure:

- **Properties**: Component configuration and state
- **Events**: Automatic onChange events for all properties
- **Methods**: Component behavior
- **Messages**: Decoupled communication via message bus
- **View**: React JSX rendering
